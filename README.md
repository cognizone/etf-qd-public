# ETF QD public data

This repository serves model and vocabulary documents at
https://data.etf-qd.cogni.zone/.

On `dev`, the ETF validation profile uses common rules from a pinned ACQF public commit.
See [publication/README.md](publication/README.md) for generation, checks and CI.
The generated `docs/model/exchange-model.ttl` is the complete ETF validation model.
